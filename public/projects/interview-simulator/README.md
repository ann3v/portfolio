# AI Job Interview Simulator screenshots

This directory is reserved for real application captures. Current visuals are native SVG architecture artwork, not product screenshots.

| File                    | Capture                                          |
| ----------------------- | ------------------------------------------------ |
| `cover.webp`            | Selected application overview                    |
| `interview-setup.webp`  | Role, type, difficulty, and length configuration |
| `active-interview.webp` | A question and answer in progress                |
| `answer-feedback.webp`  | Coaching feedback and strong-answer example      |
| `final-results.webp`    | Completed interview results                      |
| `history-resume.webp`   | Saved interviews and resume action               |

The content key is `ai-interview-simulator`: add `{ src: "/projects/interview-simulator/cover.webp", alt: "Description of the actual image" }` under that key in `src/data/media.ts` to enable the homepage and case-study cover. Other files are reserved for future galleries. Use non-private sample interview content and hide account details.
