# KosVibe screenshots

This directory is reserved for real captures from the collaborative application. The current portfolio uses labeled native SVG architecture artwork.

Recommended names:

| File                       | Capture                                         |
| -------------------------- | ----------------------------------------------- |
| `cover.webp`               | The chosen overview or business dashboard cover |
| `discovery.webp`           | Home/discovery                                  |
| `map.webp`                 | Map-based discovery                             |
| `restaurant-detail.webp`   | Restaurant information                          |
| `booking.webp`             | Reservation creation                            |
| `business-dashboard.webp`  | Business management dashboard                   |
| `business-claim.webp`      | Claim/request flow                              |
| `reservation-manager.webp` | Reservation lifecycle management                |
| `marketplace.webp`         | Local listings/contact marketplace              |

Add `kosvibe: { src: "/projects/kosvibe/cover.webp", alt: "Description of the actual image" }` in `src/data/media.ts` to enable the homepage and case-study cover. Other names establish an asset convention for future galleries; they are not automatically rendered. Remove private account and contact details before publishing.
