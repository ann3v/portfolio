# Smart Student Planner screenshots

This directory is reserved for real application captures. Current visuals illustrate the architecture in native SVG.

| File                   | Capture                                  |
| ---------------------- | ---------------------------------------- |
| `cover.webp`           | Selected mobile application overview     |
| `dashboard.webp`       | Planner dashboard                        |
| `tasks.webp`           | Task list                                |
| `task-reminders.webp`  | Task details and local reminder settings |
| `weekly-schedule.webp` | Weekly schedule                          |
| `analytics.webp`       | Progress and analytics                   |

The content key is `smart-student-planner`: add `{ src: "/projects/student-planner/cover.webp", alt: "Description of the actual image" }` under that key in `src/data/media.ts` to enable the homepage and case-study cover. Other files are reserved for future galleries. Avoid exposing private schedules or account details. Local reminders should not be described as remote push notifications.
